# Reference Priority

## Rule

Authority is role-specific.

Do not ask “which image is highest priority overall?” when different images control different facts.

## Default role precedence

For identity:
1. approved assembled/identity master
2. approved component master
3. approved production variant
4. draft
5. external inspiration

For geometry:
1. approved view/component master dedicated to that geometry
2. approved assembled master
3. approved alternate view
4. draft
5. style/mood reference

For material/color:
1. approved material/component master
2. approved assembled master
3. approved material reference
4. style reference
5. mood reference

For camera:
1. approved camera/view master
2. current edit target if already approved
3. other references

## Conflict handling

When two approved references conflict:

- identify the conflicting role;
- use the reference explicitly authoritative for that role;
- do not average incompatible geometry;
- note the conflict in the task record if it may affect downstream modeling.

## Reference count

Prefer the minimum sufficient set.

Every extra reference must justify a missing role. Redundant references can dilute control.
