# Material Lock

## Material dimensions

When a material is locked, consider:

- base color / hue family;
- roughness appearance;
- metallic vs non-metallic behavior;
- grain or brushing direction;
- scale of visible texture;
- edge wear level;
- polish level;
- reflectance character.

## Local material edits

If the user changes only one part's material:

- keep that part's geometry and position unchanged;
- keep neighboring parts unchanged;
- specify the new material in physical visual terms;
- do not let material language accidentally redesign shape.

Example:

“subtle brushed cold-silver steel, low-key linear brushing, non-mirror finish”

is better than:

“make it cooler and more premium.”

## Reference roles

A material reference controls surface appearance only unless it is also explicitly approved for geometry.

Do not import its silhouette, proportions, camera, or unrelated colors.
